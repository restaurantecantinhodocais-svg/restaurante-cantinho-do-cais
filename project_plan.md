# Cantinho do Cais - Website

## 1. Project Description
Website de página única (single-page) para o restaurante Cantinho do Cais, localizado em São Brás, Açores. O objetivo é criar uma presença online premium, acolhedora e memorável que transmita confiança e incentive visitas e reservas.

## 2. Page Structure
- `/` - Página principal (single-page com secções)
  - Hero
  - Sobre / História
  - Menu
  - Galeria
  - Testemunhos
  - Reservas
  - Contacto
  - Footer

## 3. Core Features
- [x] Hero section com imagem forte e nome do restaurante
- [x] Secção Sobre / História
- [x] Secção Menu com categorias
- [x] Galeria de fotos
- [x] Testemunhos de clientes
- [x] Sistema de reservas (calendário + modal telefone/email)
